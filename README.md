# Our winter escape

A lightweight, dependency-free countdown to a winter trip to Center Parcs. The holiday starts on 7 December 2026, and more guests join on 10 December. Both countdowns are set to 10:00 UK time (GMT).

Hover over, focus or tap either countdown to see a tooltip with days, hours and minutes. The main display remains in total hours, minutes and seconds. Press Escape to dismiss the tooltip.

The site is served as static files by GitHub Pages. After the first visit, its service worker keeps the site available offline. To run locally, serve this directory with any static HTTP server. Run the countdown unit tests with `npm test` (Node.js required).
