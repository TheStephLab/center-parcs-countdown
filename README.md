# Our winter escape

A lightweight, dependency-free countdown to a winter trip to Center Parcs. The two dates are 7 and 10 December 2026 at 10:00 UK time (GMT).

Hover over either countdown, or activate it with a mouse, touch or keyboard, to see days, hours and minutes instead of total hours, minutes and seconds.

The site is served as static files by GitHub Pages. To run locally, serve this directory with any static HTTP server. Run the countdown unit tests with `npm test` (Node.js required).
